# fuzzy-logic-three-fis

A Python implementation for the controlled comparative evaluation of Mamdani, zero-order Takagi–Sugeno, and Tsukamoto fuzzy inference systems using a common set of input membership functions, rule base, and predefined operating scenarios.

The code generates the numerical results and figures reported in the associated study and demonstrates how differences in consequent representation and output-formation mechanisms can lead to different crisp outputs under identical input and rule conditions.
